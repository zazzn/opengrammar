Features

Everything you need.
Nothing you don't.

Built for developers, writers, and privacy advocates who want complete control over their writing tools.

No servers, ever

Checking runs on your device. There is no OGrammar backend, no account, and no tracking. Any AI key you add is encrypted on your machine and used only by you.

On-device Harper engine

The Automattic Harper engine checks grammar, spelling, punctuation, and style entirely offline, as you type. Choose American, British, Canadian, or Australian English.

Bring your own AI

Optional and off by default. Add a key for OpenAI, DeepSeek, Groq, OpenRouter, or Together — or run a model 100% locally with Ollama. Your text goes straight to the provider you choose.

It learns as you write

Confirm a correction once and the local engine remembers it — no AI round-trip needed. Undo an autocorrect and it never makes that change again.

Safe with code & secrets

A protected-text engine recognizes URLs, emails, file paths, code, package names, API keys, and version strings — so suggestions never mangle the things you didn't mean to edit.

Tone & rephrase

With AI on, rewrite any selection — Polish, Formal, or Casual — or pull up three alternative phrasings, inline, with a preview before anything changes.

How it works

Local first.
AI when you want it.

A fast on-device engine handles everyday checking. Turn on AI — with your own key — for deeper rewrites. Results merge into one ranked list.

1

On-device checking

The Harper engine flags grammar, spelling, punctuation, and style as you type — offline, instantly, with nothing leaving your browser.

2

Spelling that fits the sentence

A built-in 82k-word dictionary plus an n-gram language model rank corrections by what actually fits the context, not just edit distance.

3

Optional AI, your key

Enable advanced rewrites, tone changes, or autocomplete. Text goes directly to the provider you pick — or a local Ollama model. Off by default.

Get Started

Ready in 5 minutes.

Clone, build, load. That's it.

# 1. Clone the repository
git clone https://github.com/zazzn/opengrammar.git

# 2. Build the extension (npm)
cd opengrammar/opengrammar/extension
npm install && npm run build

# 3. chrome://extensions → Developer mode → Load unpacked → select dist/
#  Optional: pick a provider + key in the popup for AI. No backend needed.
